# MONTAGEM FRITAX (Ritmada)   —   132 BPM, Fa mineur, 2:21

Morceau de **phonk brésilien** (montagem / ritmada) entièrement fabriqué de zéro :
aucun échantillon, aucun fichier externe. Chaque son est du signal calculé
(batterie tamborzão, 808 saturé, cowbell phonk, charleys, voix de synthèse).

## Structure

```
0:00  Intro      riff de cowbell + « montagem » chuchoté      (8 mesures)
0:15  Drop 1     batterie complète + 808 + refrain scandé     (16 mesures)
0:43  Coupure    la batterie s'arrête, appel « vem pro ritmo! »
0:50  Montée     souffle montant qui prépare le retour
0:57  Drop 2     plus lourd (toms doublés, 808 plus grave)    (16 mesures)
1:25  Calme      demi-temps, respiration
1:40  Drop 3     le plus fort, refrain + cri final            (16 mesures)
2:00  Outro      retour au riff, « montagem » qui s'éteint
```

## Paroles

Le refrain se chante sur 2 mesures, toutes les 8 mesures :

```
MON-TA-GEM ... RI-TMA-DA ... VEM! OH!
MON-TA-GEM ... FRI-TAX ... UH!
```

Au complet :

```
[Intro — chuchoté]
mon... ta... gem...

[Refrain]
Montagem ritmada, vem! (oh!)
Montagem Fritax, uh!

[Coupure — appel]
Vem! Pro ritmo! Vem!

[Refrain]
Montagem ritmada, vem!
Montagem Fritax, uh!
```

## Comment c'est fait

| Élément | Synthèse |
|---|---|
| Grosse caisse | sinus dont la hauteur tombe de 150 à 45 Hz + clic filtré, saturé |
| Tamborzão (toms) | sinus à hauteur tombante + peau bruitée filtrée |
| Clap | 4 rebonds de bruit dans un filtre de bande |
| Charleys | bruit passé en haut, décroissance très courte (+ roulements en fin de mesure) |
| 808 | sinus saturé, longue décroissance, glissements de hauteur, écrasé par le kick (pompage) |
| Cowbell | deux carrés désaccordés (f et f×1,48) dans un filtre de bande |
| Voix | dent de scie (cordes vocales) + banc de formants (a/e/i/o/u/m/v) + consonnes bruitées |
| Reverb | convolution avec une réponse fabriquée (bruit décroissant filtré) |
| Finition | pompage sur le kick, élargissement stéréo, limiteur doux (tangente hyperbolique) |
